To use:
1. Upload index.html to the root of your GitHub Pages repository, replacing the existing file.
2. Commit the changes.
3. Open your GitHub Pages website and refresh.

Important:
Keep a backup of your current index.html before replacing it. Verify all formulas and rates against your workplace process before relying on estimates.
